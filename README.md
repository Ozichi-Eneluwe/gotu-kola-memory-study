# Memory Enhancing Effect of Gotu Kola on Mice Exposed to Vanadium

## 📌 Project Overview
This undergraduate research investigates the neuroprotective and memory-enhancing effects of Gotu Kola (Centella asiatica) on mice exposed to vanadium toxicity.

## 🧪 Objectives
- To evaluate memory performance in mice exposed to vanadium
- To assess the effect of Gotu Kola on cognitive function
- To analyze its potential neuroprotective properties

## 🔬 Methodology
- Experimental animal study using mice
- Exposure to vanadium
- Treatment with Gotu Kola extract
- Behavioral memory tests conducted

## 📊 Findings
Gotu Kola demonstrated potential memory-enhancing and neuroprotective effects against vanadium-induced toxicity.
